# Log Interactions

Interaction logging is not implemented in the current shipped app.

## Current Entry Point

- The Home screen includes a full-width `Record new interaction` button near the top of the screen.
- The button is disabled.
- The button does not navigate, open a form, or create data.

## Future Behavior

When interaction logging is implemented, this document must describe the capture flow, required fields, validation, save behavior, error recovery, and how new interactions appear on Home.
