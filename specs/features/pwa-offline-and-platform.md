# PWA, Offline, and Platform Behavior

Scanner includes initial production-build PWA wiring through `vite-plugin-pwa`, but it does not yet provide a complete installable/offline product contract.

## Current Behavior

- The PWA plugin is configured with `registerType: "prompt"`.
- No web app manifest is currently declared.
- Workbox includes generated build assets matching `js`, `css`, `html`, `ico`, `png`, and `svg`.
- Saved interactions and custom platform options use browser `localStorage`, so they remain available offline in the same browser profile.
- QR camera scanning depends on browser camera APIs and user permission.
- Calendar export creates an `.ics` file and relies on the mobile browser/operating system to open the user's calendar flow.

## Build Output

- Production builds write generated files to `docs/`.
- The app shell can be served from the production assets generated by Vite.
- `public/CNAME` is copied into `docs/CNAME` during production builds so the GitHub Pages custom domain survives regenerated output.

Future offline work must document install prompts, service worker update UX, cache boundaries, IndexedDB behavior if adopted, and recovery rules.
